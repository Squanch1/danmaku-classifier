# 弹幕质量分级标注规范

单标签多分类任务:弹幕质量分为 **1~4 级,数值越高质量越好**。

## 等级定义

| 等级 | 名称 | 定义 | 典型例子 |
|------|------|------|---------|
| **1 级** | 垃圾/违规 | 广告引流、卖片、联系方式/网址、辱骂人身攻击、低俗色情、政治敏感 | "加V看片:xxxx"、"导演是鲨比吗?"、"视频同款立即购买" |
| **2 级** | 低质 | 无信息量的灌水:纯"哈哈哈哈"、纯表情颜文字、"打卡"、"+1"、无意义数字串、与视频内容完全无关的水评 | "哈哈哈哈哈哈"、"打卡"、"1234" |
| **3 级** | 普通 | 正常互动与情绪表达:"666"、"前方高能"、剧情/画面吐槽、队形参与、简单提问或回应、情感共鸣 | "66666"、"前方高能预警"、"这也太帅了吧" |
| **4 级** | 优质/精华 | 有信息量到高价值:剧情细节补充、有观点的相关讨论、完整句子的外文翻译、科普解释与纠错、BGM/出处提示、关键时间点导航、独到见解或创造梗 | "这里翻译:他说的是'我们会永远在一起'"、"科普:第二定律讲错了,正确表述是……" |

## 边界裁决规则

1. 纯"哈哈哈哈"/纯表情,无论多长 = **2 级**
2. "哈哈哈"+有内容的吐槽 = **3 级**
3. 简短常见互动("666"、"前方高能"、"名场面"、"泪目") = **3 级**
4. 完整句子以上的翻译 = **4 级**(不区分句子数量)
5. 指出视频中错误并给出正确信息 = **4 级**
6. 广告/联系方式/网址 = **1 级**,无例外
7. 与视频无关的灌水 = **2 级**;表达对视频/up 主的情绪 = **3 级**
8. 拿不准时取保守值 **3 级**

## Few-shot 示例(供 LLM 标注参考)

```
"哈哈哈哈哈哈" -> 2 级(纯情绪无信息量)
"前方高能预警" -> 3 级(常见互动提示)
"66666" -> 3 级(常见赞赏互动)
"加V看片:xxxxx" -> 1 级(广告引流)
"这里翻译:他说的是'我们会永远在一起'" -> 4 级(完整一句翻译)
"科普:视频里把第二定律讲错了,正确的表述是……" -> 4 级(纠错科普)
"up主说的对,这里其实是致敬了XX电影" -> 4 级(补充相关知识)
"打卡" -> 2 级(无信息量灌水)
"淦,这也太帅了吧" -> 3 级(情绪表达)
```

## 设计说明

- 原方案为五级(5 级=精华/深度科普/梗创造),因 5 级样本极度稀缺(539 条 pilot 中 0 条、定向补采 3,500 条中仅 23 条),于 **2026-09-01 并入 4 级**;
- 1/2 级边界:广告与辱骂(有害) vs 无意义灌水(无信息量);
- 2/3 级边界最模糊:纯"哈哈"=2 级,"哈哈"+吐槽=3 级;
- 4 级核心判据:**是否给其他观众带来了新信息**。

## 数据分布参考(2026-09-01 实测)

## 训练集 EDA 关键发现(2026-09-01,`bert/src/eda_train.py`)

### 文本长度

- 均值 29.6 字(自然态均值 10.7),分布呈"两头翘":1-5 字 18.8%、6-10 字 20.4%、31-50 字 21.9%、51-100 字 21.5% —— 定向补采拉偏了长度分布
- 长度×标签:31-50 字中 4 级占 **63.9%**,1-5 字中 2 级占 **71.8%**;"越长越优质"的规律强
- ⚠️ 长度在训练/验证间分布差异大,模型可能学到"长文本≈4级"的捷径

### mode × 标签(回填自原始池)

| mode | 1级 | 2级 | 3级 | 4级 |
|------|-----|-----|-----|-----|
| 滚动(1) | 2.1% | 36.4% | 30.1% | 31.3% |
| 底部(4) | 0.0% | 27.7% | 66.2% | 6.1% |
| 顶部(5) | 1.4% | 32.6% | 39.3% | 26.7% |

"底部弹幕=高质量"再次被证伪(底部 66% 是 3 级,4 级仅 6.1%);mode 无分类区分度,不建议作为特征。

### 各等级高频 n-gram(训练集)

| 等级 | 特征词 | 解读 |
|------|--------|------|
| 1级 | `ht/li/ll/tt/al/tp/bi` 等英文字母串 | 网址/链接类广告的语言指纹 |
| 2级 | `哈哈`(1709)、`99`(1558)、`11`(1217)、`志鑫/朱志`(粉丝刷屏)、`恭喜` | 灌水 + 粉丝控评刷屏 |
| 3级 | `66`(1001)、正常互动词 | 常见互动 |
| 4级 | `就是/其实/不是/自己/没有/可以/应该` | 论述性、分析性语言指纹 |

⚠️ 2 级混有粉丝刷屏人名("志鑫/朱志"各 600+ 次),模型可能学到"含人名的短句=2级"的偏见捷径。
