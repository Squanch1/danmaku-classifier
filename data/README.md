# 弹幕质量分级项目(数据说明)

## 原始数据

- **来源**: B站公开弹幕接口(`comment.bilibili.com`),2026-08-31 采集自热门列表
- **规模**: 200000 条,文本全局去重,覆盖 135 个视频
- **格式**: JSONL,每行一条:

| 字段 | 说明 |
|------|------|
| `text` | 弹幕文本(UTF-8,已处理 GBK 历史遗留编码问题) |
| `time_s` | 在视频中的出现时间(秒) |
| `mode` | 弹幕类型:1-3 滚动,4 底部,5 顶部 |
| `bvid` / `title` | 来源视频 |

- **统计**: 平均长度 11.4 字,89.1% ≤ 20 字,59.7% ≤ 10 字;约 0.2% 文本因源头编码损坏无法完全恢复
- **采集脚本**: `python data/scripts/fetch_danmaku.py --target 200000 --pages 20`(仅标准库,可复现;支持 `--append` 续采)

## 标注方案(四级质量)

- **1 级(垃圾/违规)**: 广告引流、卖片、联系方式/网址、辱骂人身攻击、低俗色情、政治敏感
- **2 级(低质)**: 无信息量的灌水,如纯"哈哈哈哈"、纯表情颜文字、"打卡"、"+1"、无意义数字串、与视频内容完全无关的水评
- **3 级(普通)**: 正常互动与情绪表达,如"666"、"前方高能"、剧情/画面吐槽、队形参与、简单提问或回应、情感共鸣
- **4 级(优质/精华)**: 有信息量到高价值,包括剧情细节补充、有观点的相关讨论、完整句子的外文翻译、科普解释与纠错、BGM/出处提示、关键时间点导航、独到见解或创造梗

> 原 5 级方案因 5 级极其稀缺(539 条 pilot 里 0 条、定向补采 1851 条里仅 23 条)于 2026-09-01 并入 4 级。

## 标注数据(5,027 条)

三路标注合并去重:

| 来源 | 条数 | 4 级占比 | 说明 |
|------|------|----------|------|
| pilot 分层抽样 | 539 | 13.0% | 按 mode×长度桶分层,保底抽样 |
| 候选池定向补采 | 3,500 | 45.7% | mode4+关键词+长文本挖掘,4 级产出率约 5 倍 |
| 随机批量标注 | 988 | 9.4% | 按 bvid 均匀抽样 |

**合并分布**: 1 级 54(1.1%) / 2 级 940(18.7%) / 3 级 2271(45.2%) / 4 级 1762(35.1%)

**划分**(按标签分层,固定种子 42): train 3518(70%) / val 754(15%) / test 755(15%)

> 注意: 这是富集分布(4 级刻意过采样),适合训练;上线评估建议另备自然分布测试集。

## EDA 关键发现

- 长度×标签: **"越长越优质"只在 50 字以内成立**(31-50 字 4 级占 64.9%,为黄金区;51 字以上混入长刷屏和广告,2 级回升到 32.4%)
- mode×标签: "底部弹幕=字幕=高质量"被证伪(底部弹幕 66% 是普通互动,4 级仅 6.1%)
- 1 级中位长度 52 字(广告/长篇辱骂),长度本身是强特征

## 基线模型对比(测试集 755 条)

| 模型 | 特征 | accuracy | macro-F1 |
|------|------|----------|----------|
| **fastText char_auto** | 字符级 + autotune | **0.740** | **0.627** |
| fastText char_default | 字符级 | 0.728 | 0.515 |
| fastText word_auto | jieba 词 + autotune | 0.744 | 0.540 |
| fastText word_default | jieba 词 | 0.703 | 0.470 |
| 随机森林(balanced) | jieba 词 TF-IDF + 网格搜索 | 0.511 | 0.474 |

- 字符切分优于词切分(弹幕黑话/新词多,jieba 易切错)
- autotune 调参收益显著(macro-F1 +7~10 个点)
- RF 的网格搜索必须用 `scoring="f1_macro"`,默认 accuracy 会选出让稀有类坍缩的模型
